# Vendored CLIFF fixtures

This directory contains read-only copies of the CLIFF specification examples, references and conformance fixtures used by the test suite.

- Source repositories, commit SHAs and licenses are recorded in `SOURCE.json`.
- Upstream license texts are in `LICENSE-cliff` and `LICENSE-cliff-test`.
- Do not edit these files to make a test pass. Fix the implementation or refresh the fixture from its source repository.

The sync check never deletes files. It verifies the recorded commit SHAs against sibling checkouts when they are available.
